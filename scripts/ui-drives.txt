# The browser drives, run as a suite — one name per line.

# ⚠️ WHY THIS FILE EXISTS, and it is not tidiness.
#
# Until 12 November none of these ran anywhere. They were written one at a time
# beside the feature each covers, and "the drives pass" was an assumption
# nobody had tested: running all 42 against a fresh stack for the first time
# found two that could not fail at all, nine red, and — among the red — one
# live product defect and one standing-rule violation. The other nine reds were
# checks that had quietly stopped measuring what they claimed, several of them
# for months. docs/E2E-AUDIT.md is the whole account.
#
# A drive that is in the repository and in no workflow is worse than no drive,
# because the checklist row claiming its coverage is claiming a gate that does
# not exist. So the list lives here, in one reviewable place, and
# scripts/ui-drives.sh fails if a name in it has no file.
#

#   refresh-race-drive    ) payment rows and the second database they need
#   inbox-race-drive      )

#   phone-signup-ui-drive     WhatsApp, which is switched off (Meta bills per
#   phone-only-ui-drive       message), and phone sign-up is unreachable in
#                             practice — docs/OUTSTANDING.md §29. They are not
#                             listed because they would fail every run; they
#                             are not deleted because the day the channel comes
